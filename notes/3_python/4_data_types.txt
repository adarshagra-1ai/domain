4  --  Data types  (int, float, str, bool)

1)  What a "data type" is

Every value in Python has a TYPE. The type tells Python what kind of value it is and what operations make sense on it.

     42       --  an integer (a whole number)
     3.14     --  a float (a decimal number)
     "hello"  --  a string (text)
     True     --  a boolean (a yes/no value)

The type controls what you can do with the value. You can multiply two integers, but you cannot multiply two strings the same way. Knowing the type is the first thing you need to check about a variable before using it in an operation.

2)  The four basic types in this section

     int      ->  whole numbers
     float    ->  decimal numbers
     str      ->  text
     bool     ->  True or False

Python has more built-in types (list, dict, tuple, set, and others), and those hold many values at once. Here we focus on the four SCALAR types  --  values that hold a single piece of data at a time.

3)  int  --  integer  (whole numbers)

Write them directly, no quotes.

Code:

     age  = 25
     year = 2026
     temp = -5
     big  = 1_000_000

Notes:

  -  No decimal point.
  -  Can be negative (leading  -  ).
  -  Underscores  _  can be used as digit separators for readability ( 1_000_000  reads as one million; Python treats it exactly as  1000000 ).

Basic arithmetic:

     +     addition           7 + 3    ->  10
     -     subtraction        7 - 3    ->   4
     *     multiplication     7 * 3    ->  21
     /     division           7 / 3    ->   2.333...  (always returns a float)
     //    floor division     7 // 3   ->   2         (divide, drop the fractional part)
     %     modulo             7 % 3    ->   1         (the remainder after dividing)
     **    exponent           2 ** 3   ->   8         (2 raised to the power of 3)

Example:

Code:

     x = 7
     y = 3
     print(x + y)
     print(x // y)
     print(x % y)

Output:
     10
     2
     1

4)  float  --  floating-point  (decimal numbers)

Write them with a decimal point.

Code:

     pi    = 3.14
     price = 99.99
     ratio = 0.5
     tiny  = -0.001

Notes:

  -  A decimal point makes the number a float, even if the fractional part is 0 (so  2.0  is a float, not an int).
  -  All the arithmetic operators from  int  work on floats too.

Code:

     print(6 / 2)
     print(2.0 + 3)

Output:
     3.0
     5.0

6 / 2  gave  3.0  (not  3 ) because  /  always returns a float. Mixing an int with a float ( 2.0 + 3 ) also gives a float.

5)  str  --  string  (text)

Text of any length, wrapped in quotes.

Code:

     name   = "adarsh"
     city   = 'delhi'
     empty  = ""
     digits = "12345"

Notes:

  -  "12345"  is a STRING, not a number, because it is inside quotes.
  -  An empty string  ""  is a valid value (a string with zero characters).

6)  bool  --  boolean  (True or False)

Only two possible values, both CAPITALIZED:

     True
     False

They come from two places: COMPARISONS (like  5 > 3 ) and direct assignment ( is_active = True ).

Code:

     print(5 > 3)
     print(5 == 3)
     print("a" == "a")

Output:
     True
     False
     True

The  ==  operator (two equals signs) means "is equal to", and it hands back a bool. It is a different operator from  =  (single equals), which assigns a value and hands back nothing.

You can also assign booleans directly:

     is_active = True
     is_admin  = False

7)  Check the type  --  type()

The built-in function  type(x)  returns the type of the value  x .

Code:

     print(type(42))
     print(type(3.14))
     print(type("hello"))
     print(type(True))

Output:
     <class 'int'>
     <class 'float'>
     <class 'str'>
     <class 'bool'>

Read  <class 'int'>  as "the type is int ". The word  class  is Python's own name for a type, and it shows up here because every type is built the same way underneath.  type()  is your quick way to answer "what type is this value?".

8)  Convert between types

Python has built-in "conversion" functions:

     int(x)     ->  convert  x  to an int
     float(x)   ->  convert  x  to a float
     str(x)     ->  convert  x  to a string
     bool(x)    ->  convert  x  to a boolean

They take a value of one type and produce a NEW value of the target type. The original value is not changed.

Conversion happens in two ways, and the difference is simply WHO asks for it.

EXPLICIT  --  you ask, by calling one of those functions yourself.

     x = int("42")

IMPLICIT  --  Python does it on its own, without being asked, when one expression mixes two types it can safely line up.

Code:

     result = 1 + 2.0
     print(result)
     print(type(result))

Output:
     3.0
     <class 'float'>

You wrote an  int  and a  float  in one sum. Python widened the  1  into  1.0  by itself and gave back a float. Nothing in the line asked for that.

Python only does this where no information is lost. It will never quietly turn a string into a number, which is why this fails instead of guessing:

     print("42" + 1)
     TypeError: can only concatenate str (not "int") to str

Python cannot tell whether you meant to add two numbers or to join two pieces of text, so it refuses rather than guessing. Say which one you meant:

     print(int("42") + 1)     ->  43
     print("42" + str(1))     ->  421

A word on "CASTING": you will meet it in tutorials, used to mean the explicit kind. It comes from languages like C and Java, where a cast can reinterpret the same bits as a different type.  int("42")  does nothing of the sort  --  it builds a brand new object and leaves the string alone. For Python, "conversion" is the accurate word.

Common conversions:

Code:

     print(int(3.7))
     print(int("42"))
     print(float("3.14"))
     print(str(2026))
     print(bool(1))
     print(bool(0))

Output:
     3
     42
     3.14
     2026
     True
     False

Notes:

  -  int(3.7)  gives  3  (drops the fractional part; does NOT round).
  -  int("42")  works because the string looks like a valid whole number. A string that does not look like one fails outright:

        int("hello")
        ValueError: invalid literal for int() with base 10: 'hello'

  -  bool(0)  is  False .  bool(1)  , or any non-zero number, is  True .

9)  round()  --  shorten a float

int()  chops the fractional part off. When you want proper rounding instead, use the built-in  round(number, decimals) . The second argument is HOW MANY decimal places to keep.

Code:

     print(round(3.145678, 2))
     print(round(3.145678, 1))
     print(round(3.145678, 0))
     print(round(3.7))

Output:
     3.15
     3.1
     3.0
     4

Notes:

  -  round()  returns a FLOAT (except with no second argument, where it returns an int).  round(3.145678, 0)  gives  3.0 , not  3 .
  -  Trailing zeros disappear on print, because the float  1.50  and the float  1.5  are the same number:

Code:

     x = round(1.5023, 2)
     print(x)
     print(x == 1.50)

Output:
     1.5
     True

  -  round()  changes the NUMBER itself, not the way it is displayed.
