22  --   __main__.py  walkthrough  (docstring and imports)

A walkthrough of the header portion of a typical  __main__.py  file, top to bottom. We assume the file lives inside a package  mypackage , runnable via  python -m mypackage .

1)  Module docstring

     """my-engine CLI  --  run the engine."""

A DOCSTRING at the top of a module, same as in  __init__.py . One-line human description of the file: this is the CLI (Command-Line Interface) of the engine.

2)  The  from __future__ import annotations  line

     from __future__ import annotations

Older Python 3.x did not accept the modern type-hint style like  dict | None . This line tells Python to treat every type hint as plain text instead of trying to evaluate it, so a file using modern hints still loads on an older Python.

3)  Standard library imports

     import argparse
     import asyncio
     import json
     import signal

Four modules from Python's STANDARD LIBRARY (they ship with Python  --  no  pip install  needed). Here is what each one is doing in this file.

  -   argparse   --  builds a COMMAND-LINE PARSER. It reads the flags the user typed after the program name and turns them into a plain Python object, so  --config ./data  becomes  args.config == "./data" .

  -   asyncio   --  Python's built-in ASYNCHRONOUS programming library. It lets one program handle many tasks that WAIT (for network replies, timers, hardware events) using a single thread.

  -   json   --  reads and writes JSON (JavaScript Object Notation) text. Used here to load a config file.

  -   signal   --  gives access to operating-system SIGNALS, the small messages the OS (Operating System) sends to a running program. Pressing  Ctrl + C  sends one.

4)  Relative imports

     from .clock import RealClock
     from .core import Engine

A leading dot means "the current package". The current package is  mypackage , so:

  -   .clock   ->   mypackage/clock.py   ->  grabs the  RealClock  class
  -   .core    ->   mypackage/core.py    ->  grabs the  Engine  class

5)  What has run so far

Nothing has done real work yet. Python has only loaded modules and pulled some classes and functions into the file's namespace. Real execution starts when  main()  is called at the very bottom of the file.
