7  --  Dictionaries  (create, read, update, delete key-value pairs)

1)  What a dictionary is

A DICTIONARY (or "dict") is a collection of KEY  ->  VALUE pairs. Each key stores a single value. You look up a value by giving its key.

Key properties:

  -  Each key is UNIQUE inside one dict. Assigning a value to an existing key REPLACES the old value.
  -  A dict is MUTABLE  --  you can add, change, and remove key-value pairs after creation.
  -  Since Python 3.7, dicts preserve INSERTION ORDER  --  items come out in the order they were added.

2)  Creating a dictionary

Use curly braces  { }  with items in the form  key: value  , separated by commas.

Code:

     empty  = {}
     person = {"name": "adarsh",
               "age": 25,
               "city": "delhi"}
     scores = {"math": 90, "sci": 85, "eng": 78}
     mixed  = {"count": 3,
               "active": True,
               "tags": ["python", "web"]}

Notes:

  -  An empty dict is  {}  (zero items).
  -  A key can be any IMMUTABLE type: string, number, or tuple (a tuple being a fixed sequence of values that cannot be changed). Strings are the common choice.
  -  Values can be any type: strings, numbers, lists, other dicts, anything.
  -  A single dict may have keys of different types.

Alternative:  dict()  constructor

Code:

     person = dict(name="adarsh", age=25)
     print(person)

Output:  {'name': 'adarsh', 'age': 25}

This form only works when keys are valid Python variable names. For any key type, use the  { }  form.

Two things go wrong while creating one:

  -  The same key written twice is not an error, and that is the danger. Only the LAST value survives, silently.

        d = {"x": 1, "x": 2}
        print(d)
        {'x': 2}

  -  A list cannot be a key, because a key has to be immutable and a list is not. A tuple can, so  {(1, 2): "hello"}  works.

        d = {[1, 2]: "hello"}
        TypeError: unhashable type: 'list'

3)  Reading a value

Use square brackets  d[key]  , like indexing a list, but with the KEY (not a number) inside.

Code:

     person = {"name": "adarsh", "age": 25}
     print(person["name"])
     print(person["age"])

Output:
     adarsh
     25

If the key does NOT exist, this raises a  KeyError :

Code:

     print(person["email"])

Run:

     KeyError: 'email'

Safer:  d.get(key, default)

     d.get(key)              returns the value at key, or  None  if the key is missing.
     d.get(key, default)     returns the value at key, or  default  if the key is missing.

Code:

     person = {"name": "adarsh", "age": 25}
     print(person.get("name"))
     print(person.get("email"))
     print(person.get("email", "not set"))

Output:
     adarsh
     None
     not set

4)  Adding or updating a value

Assign to a key with  = .

  -  Key does NOT exist  ->  ADDS a new key-value pair.
  -  Key already exists  ->  REPLACES the old value.

Code:

     person = {"name": "adarsh"}
     person["age"]  = 25
     person["name"] = "adarsh k"
     print(person)

Output:  {'name': 'adarsh k', 'age': 25}

Bulk update  --  d.update(other)

Adds all key-value pairs from another dict. Overwrites existing keys.

Code:

     a = {"x": 1, "y": 2}
     b = {"y": 99, "z": 3}
     a.update(b)
     print(a)

Output:  {'x': 1, 'y': 99, 'z': 3}

5)  Removing a key-value pair

  (a)   del d[key]

        Code:

           person = {"name": "adarsh", "age": 25}
           del person["age"]
           print(person)

        Output:  {'name': 'adarsh'}

        A missing key raises  KeyError .

  (b)   d.pop(key)  --  remove and RETURN the value.

        Code:

           person = {"name": "adarsh", "age": 25}
           v = person.pop("age")
           print(v)
           print(person)

        Output:
           25
           {'name': 'adarsh'}

        A missing key raises  KeyError  , unless you pass a default:

           v = person.pop("email", None)

  (c)   d.clear()  --  empty the dict.

        Code:

           person = {"name": "adarsh", "age": 25}
           person.clear()
           print(person)

        Output:  {}

6)  Checking for a key  --  in

Code:

     person = {"name": "adarsh", "age": 25}
     print("name" in person)
     print("email" in person)
     print("email" not in person)

Output:
     True
     False
     True

in  checks KEYS by default, not values.

7)  Iterating

  (a)   for key in d:

        Code:

           person = {"name": "adarsh", "age": 25}
           for k in person:
               print(k)

        Output:
           name
           age

  (b)   d.keys()   --  view of all keys.
        d.values() --  view of all values.
        d.items()  --  view of (key, value) pairs.

        Code:

           person = {"name": "adarsh", "age": 25}
           print(list(person.keys()))
           print(list(person.values()))
           print(list(person.items()))

        Output:
           ['name', 'age']
           ['adarsh', 25]
           [('name', 'adarsh'), ('age', 25)]

  (c)   Iterate as key and value together:

        Code:

           person = {"name": "adarsh", "age": 25}
           for k, v in person.items():
               print(f"{k} -> {v}")

        Output:
           name -> adarsh
           age -> 25
