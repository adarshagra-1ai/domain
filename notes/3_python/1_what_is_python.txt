1  --  What Python is; check install

1)  What Python is

Python is a programming language  --  a set of rules for writing instructions a computer can run.

Facts you need for now:

  -  One of the most popular languages, used for web backends, data science, automation, and AI (Artificial Intelligence).
  -  Syntax is close to plain English, so it is beginner-friendly.
  -  Files with Python code have the extension  .py .

2)  Python 2 vs Python 3  --  use Python 3

Python has two major version families:

  -  Python 2  --  released in 2000, retired in 2020. Do NOT learn or use it.
  -  Python 3  --  current, in active development.

On most modern systems the command name  python2  does not exist anymore. Everything we write will run under Python 3.

3)  Check if Python is installed

Open a terminal and run:

     python3 --version

Expected output:

     Python 3.11.2

Short form of the same command:

     python3 -V

If Python is installed, both commands print the version and return you to the prompt.

That version is three separate numbers joined by dots, read left to right:

     3      MAJOR   the language family. Python 2 code does not run here.
     11     MINOR   a feature release. Each one adds new features while keeping
                    old code working. A new minor version arrives roughly yearly.
     2      PATCH   bug and security fixes only, no new features.

Yours will differ depending on how new your system is. Any  3.something  is fine for us.

One trap:  3.11  is NEWER than  3.9 . Each number counts up on its own, so 9 is followed by 10 and then 11. It is not a decimal, so do not read  .11  as smaller than  .9 .

When a tutorial asks for "Python 3.10 or newer", it means the first two numbers. The patch number almost never matters.

If Python is NOT installed, you will see this instead of a version:

     bash: python3: command not found

In that case Python needs installing.

4)  Installing Python if missing

Most modern Linux distributions ship Python 3 pre-installed. If yours does not, install it with the package manager. On Ubuntu, Debian and Linux Mint that is:

     adarsh@laptop:~$  sudo apt install python3

Verify after install:

     python3 --version
     Python 3.11.2

5)  python  vs  python3  --  a common gotcha

Some systems also have a shorter command called  python . Behavior varies:

  -  On modern Ubuntu / Debian / Raspberry Pi OS,  python  does not exist by default; only  python3  is installed. Typing  python  gives  "command not found" .
  -  On some setups  python  is an alias pointing to Python 3. Then  python  and  python3  behave the same.
  -  On very old systems,  python  used to mean Python 2. That is gone now, but you may still see old tutorials that assume it.

Rule for us:  always type  python3  explicitly. It works on every modern Linux without surprises.

6)  python3 on its own  --  the interactive prompt

Typing  python3  with nothing after it does not run a file. It opens Python's INTERACTIVE PROMPT, where you type one line of Python at a time and it runs the moment you press Enter.

     adarsh@laptop:~$  python3
     Python 3.11.2 (main, Mar 13 2023, 10:26:41) [GCC 12.2.0] on linux
     Type "help", "copyright", "credits" or "license" for more information.
     >>>

The prompt is now  >>>  instead of your usual shell prompt. That change is the signal that you have left the shell and are inside Python.

     >>> 2 + 2
     4

Useful for testing one small thing without creating a file at all.

To leave, call  exit()  or press Ctrl + D. Either one drops you back to the shell prompt.

     >>> exit()
     adarsh@laptop:~$

The trap: while  >>>  is showing, shell commands do not work, because you are talking to Python and not to the shell.

     >>> ls
     Traceback (most recent call last):
       File "<stdin>", line 1, in <module>
     NameError: name 'ls' is not defined
