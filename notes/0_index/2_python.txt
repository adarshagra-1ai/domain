Python  --  Python from zero

Python has 19 small parts:

   1   What Python is; check install
       ( python3 --version )

   2   First program: print("hello") in a .py
       file and run it

   3   Variables and naming rules

   4   Data types: int, float, str, bool

   5   Strings and common string operations

   6   Lists: create, add, remove, index, slice

   7   Dictionaries: create, read, update,
       delete key-value pairs

   8   Tuples: immutable ordered collections;
       when to use them

   9   Sets: unique unordered collections;
       when to use them

   10  Conditions: if / elif / else,
       truthy / falsy

   11  Loops: for, while, break, continue,
       range

   12  Functions: def, arguments, return,
       default arguments, *args, **kwargs,
       scope

   13  Reading and writing files: open, with,
       read, write, modes ( r , w , a )

   14  Modules and import: own module,
       standard library, third-party module

   15  Errors: try / except / else / finally,
       raising errors

   16  Classes: class, __init__, self,
       methods, attributes, and a working
       look at inheritance

   17  Type hints: variables, function
       params, return types, Optional, List,
       Dict

   18  Virtual environment: what and why,
       create ( python3 -m venv .venv ),
       activate, deactivate

   19  pip and requirements.txt workflow
