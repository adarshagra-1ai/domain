PHASE A  --  Python from zero

Phase A has 19 small parts:

   A.1   What Python is; check install
         ( python3 --version )

   A.2   First program: print("hello") in a .py
         file and run it

   A.3   Variables and naming rules

   A.4   Data types: int, float, str, bool

   A.5   Strings and common string operations

   A.6   Lists: create, add, remove, index, slice

   A.7   Dictionaries: create, read, update,
         delete key-value pairs

   A.8   Tuples: immutable ordered collections;
         when to use them

   A.9   Sets: unique unordered collections;
         when to use them

   A.10  Conditions: if / elif / else,
         truthy / falsy

   A.11  Loops: for, while, break, continue,
         range

   A.12  Functions: def, arguments, return,
         default arguments, *args, **kwargs,
         scope

   A.13  Reading and writing files: open, with,
         read, write, modes ( r , w , a )

   A.14  Modules and import: own module,
         standard library, third-party module

   A.15  Errors: try / except / else / finally,
         raising errors

   A.16  Classes: class, __init__, self,
         methods, attributes, and a working
         look at inheritance

   A.17  Type hints: variables, function
         params, return types, Optional, List,
         Dict

   A.18  Virtual environment: what and why,
         create ( python3 -m venv .venv ),
         activate, deactivate

   A.19  pip and requirements.txt workflow
