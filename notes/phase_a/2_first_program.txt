A.2  --  First Python program

1)  What we will do

Write a one-line Python program that prints
the word  hello  to the terminal, save it as
a  .py  file, and run it with  python3 .


2)  Create the file

Two easy ways to create  hello.py .


Way A  --  from the terminal (no editor
           needed):

     adarsh@laptop:~$  echo 'print("hello")' > hello.py

Two new pieces here:

  -  echo  is a shell command that prints
     the text you give it. On its own,

        adarsh@laptop:~$  echo hello
        hello

     just prints  hello  to the screen.

  -  The  >  symbol REDIRECTS the output of
     the command on its left into the file
     on the right, instead of printing it
     to the screen. If the file does not
     exist, it is created. If it exists,
     its contents are OVERWRITTEN with the
     new output.

So the full line  echo 'print("hello")' > hello.py
takes the text  print("hello")  and writes
it into a new file called  hello.py .

Both  echo  and  >  will be studied in more
detail in a later phase. For now use this
one-liner as a quick "write one line to a
file" trick.

Verify what got written:

     adarsh@laptop:~$  cat hello.py
     print("hello")


Way B  --  in a text editor:

Open any text editor (VS Code, gedit, your
IDE, etc.), create a new file named
hello.py  in your current folder, put this
one line inside:

     print("hello")

Save the file.


3)  What each piece of  print("hello")  means

     print      ->  the NAME of a built-in
                    Python function that
                    prints text to the
                    screen.

     ( ... )    ->  parentheses  --  they
                    say "CALL this function
                    with the values inside".

     "hello"    ->  a STRING (a piece of
                    text). Strings in Python
                    are wrapped in double
                    quotes  "..."  or
                    single quotes  '...' .
                    Both work.

The whole line reads as:  "call the  print
function with the string  hello ".


4)  Run the file

Make sure your CWD is the folder that
contains  hello.py  (use  pwd  to check,
cd  if needed).

     adarsh@laptop:~$  python3 hello.py
     hello

That is your first program. Python read the
file, ran the one line, printed  hello ,
and returned you to the prompt.

Two things happened, in order:

  1)  You typed  python3 hello.py .
  2)  The  python3  program opened
      hello.py , executed each line top to
      bottom, then exited.

python3  is the INTERPRETER. Its job is to
read  .py  files and run them.


5)  Try small variations

Same file, different content, same run
command. Edit  hello.py , save, re-run.


Change the text:

     print("hello, world")

Run:

     adarsh@laptop:~$  python3 hello.py
     hello, world


Print a number:

     print(2025)

Run:

     adarsh@laptop:~$  python3 hello.py
     2025

Numbers do NOT need quotes.  2025  is a
number, not a string.


Two lines of output:

     print("line 1")
     print("line 2")

Run:

     adarsh@laptop:~$  python3 hello.py
     line 1
     line 2

Each  print  call ends with a newline, so
the next  print  starts on a fresh line.


6)  Common errors

  (a)   File not found

        adarsh@laptop:~$  python3 hello.py
        python3: can't open file '/home/adarsh/hello.py': [Errno 2] No such file or directory

        Wrong CWD, or the file is not
        exactly  hello.py . Fix with  pwd
        and  ls .


  (b)   Missing quotes

        Content:  print(hello)

        Run:

        adarsh@laptop:~$  python3 hello.py
        Traceback (most recent call last):
          File "hello.py", line 1, in <module>
            print(hello)
        NameError: name 'hello' is not defined

        Without quotes, Python thinks  hello
        is a variable name (not text).
        Since no such variable was defined,
        it errors. Add the quotes:
        print("hello") .


  (c)   Mismatched quotes

        Content:  print("hello')

        Run:

        adarsh@laptop:~$  python3 hello.py
          File "hello.py", line 1
            print("hello')
                       ^^^^^^^^^
        SyntaxError: unterminated string literal

        Opening quote and closing quote must
        MATCH: both double  " ... "  or
        both single  ' ... '  .


  (d)   python3 not found

        adarsh@laptop:~$  python3 hello.py
        bash: python3: command not found

        Python is not installed. Go back to
        A.1 section 5.


Once you can create  hello.py , edit it,
and run it with  python3 , you have the
basic Python workflow. In A.3 we start
storing data with variables.
