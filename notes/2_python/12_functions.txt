12  --  Functions  (def, arguments, return, default arguments, *args, **kwargs, scope)

1)  What a function is

A FUNCTION is a named block of code you can run whenever you want, as many times as you want. Instead of copying the same code in many places, you write it once and CALL it by name.

A function can:

  -  take INPUT values (parameters)
  -  do some work
  -  RETURN a value back to the caller


2)  Defining a function

Syntax:

     def <name>(<parameters>):
         <indented block>
         return <value>       (optional)

Rules:

  -  def  starts the definition.
  -  <name>  follows the same naming rules as variables (section 3): snake_case, descriptive.
  -  (<parameters>)  is a comma-separated list, possibly empty.
  -  The header ends with a colon  : .
  -  The block below must be INDENTED.


Example  --  no parameters, no return:

Code:

     def greet():
         print("hello")

     greet()
     greet()

Output:
     hello
     hello

Defining a function does NOT run its body. It just remembers the definition. The body runs only when you CALL the function ( greet() ).


3)  Parameters and arguments

  -  A PARAMETER is a name in the function definition (inside  ( ) ).
  -  An ARGUMENT is the actual VALUE passed when the function is called.

Code:

     def greet(name):
         print(f"hello, {name}")

     greet("adarsh")
     greet("priya")

Output:
     hello, adarsh
     hello, priya

Here  name  is the parameter;  "adarsh"  and  "priya"  are the arguments.


Multiple parameters, comma-separated:

Code:

     def add(x, y):
         print(x + y)

     add(3, 5)
     add(10, 20)

Output:
     8
     30


4)  return  --  send a value back

The  return  statement ends the function and hands a value back to the caller. The caller can save it in a variable, print it, or use it in an expression.

Code:

     def add(x, y):
         return x + y

     total = add(3, 5)
     print(total)
     print(add(1, 1) + add(2, 2))

Output:
     8
     6


Notes:

  -  A function without  return  returns  None  by default.
  -  You can  return  early to end the function before the last line.


Code:

     def divide(a, b):
         if b == 0:
             return None
         return a / b

     print(divide(10, 2))
     print(divide(10, 0))

Output:
     5.0
     None


Returning multiple values (via a tuple):

Code:

     def min_max(nums):
         return min(nums), max(nums)

     lo, hi = min_max([3, 1, 4, 1, 5, 9, 2, 6])
     print(lo, hi)

Output:  1 9

A comma-separated  return  packs the values into a tuple. Unpacking (see section 8) splits them out.


5)  Default arguments

Give a parameter a DEFAULT value with  = . The caller can then skip that argument.

Code:

     def greet(name, greeting="hello"):
         print(f"{greeting}, {name}")

     greet("adarsh")
     greet("priya", "hi")

Output:
     hello, adarsh
     hi, priya

Rule: parameters WITH defaults must come AFTER parameters WITHOUT defaults.

     def bad(x=1, y): ...       <-  invalid


6)  Positional vs keyword arguments

You can pass arguments by POSITION (the usual way) or by KEYWORD ( name=value ).

Code:

     def rectangle(width, height):
         print(width * height)

     rectangle(3, 4)
     rectangle(width=3, height=4)
     rectangle(height=4, width=3)

Output:
     12
     12
     12

Keyword arguments make the intent clear at the call site and let you skip earlier optional arguments.


7)  *args  --  variable number of positional arguments

Sometimes you do not know in advance how many positional arguments the caller will pass. Use  *args  in the parameter list.

The name  args  is just a convention; you can pick any name.

Inside the function,  args  is a TUPLE of the extra positional arguments.

Code:

     def total(*nums):
         result = 0
         for n in nums:
             result = result + n
         return result

     print(total(1, 2, 3))
     print(total(10, 20))
     print(total())

Output:
     6
     30
     0


8)  **kwargs  --  variable number of keyword arguments

Same idea, but for KEYWORD arguments. Inside the function,  kwargs  is a DICT of name -> value.

Code:

     def show(**info):
         for key, value in info.items():
             print(f"{key} = {value}")

     show(name="adarsh", age=25, city="delhi")

Output:
     name = adarsh
     age = 25
     city = delhi


You can combine both in one function:

Code:

     def demo(a, b, *args, **kwargs):
         print(a, b, args, kwargs)

     demo(1, 2, 3, 4, x=10, y=20)

Output:
     1 2 (3, 4) {'x': 10, 'y': 20}

Order in the parameter list:  regular ,  *args , then  **kwargs .


9)  Scope  --  where a name is visible

Names created INSIDE a function are LOCAL to that function. They exist only while the function runs. From outside the function, they do not exist.

Code:

     def demo():
         x = 100
         print(x)

     demo()
     print(x)

Run:
     100
     NameError: name 'x' is not defined

x  was born inside  demo  and died when  demo  finished.


Names created OUTSIDE any function are GLOBAL. They are visible everywhere, including inside functions (for READING).

Code:

     total = 100

     def show():
         print(total)

     show()

Output:  100


Assigning to a name inside a function creates a NEW LOCAL name, even if a global with the same name exists:

Code:

     total = 100

     def bump():
         total = 200
         print(total)

     bump()
     print(total)

Output:
     200
     100

The global  total  was NOT changed. The function created its own local  total .


To modify a global from inside a function, declare it with  global :

Code:

     total = 100

     def bump():
         global total
         total = 200

     bump()
     print(total)

Output:  200

In most cases, avoid  global . Prefer to return a new value from the function and assign it in the caller.


10)  Docstring  (brief)

The first string inside a function is its DOCSTRING  --  a short description of what the function does. Tools and editors show it as help text.

Code:

     def add(x, y):
         """Return the sum of x and y."""
         return x + y

     print(add.__doc__)

Output:  Return the sum of x and y.

Docstrings are optional. Add them for functions that do non-obvious work.


11)  Common errors

  (a)   Wrong number of arguments

        Code:

           def add(x, y):
               return x + y
           add(1)

        Run:

           TypeError: add() missing 1
           required positional argument: 'y'

        Pass all required arguments, or give them defaults in the definition.


  (b)   Non-default parameter after default

        Code:

           def bad(x=1, y):
               return x + y

        Run:

           SyntaxError: parameter without a
           default follows parameter with a
           default

        Parameters with defaults must come AFTER those without.


  (c)   Forgetting to return

        Code:

           def add(x, y):
               x + y

           result = add(3, 5)
           print(result)

        Output:  None

        The function COMPUTED  x + y  but never returned it. Without a  return , the function gives back  None .
