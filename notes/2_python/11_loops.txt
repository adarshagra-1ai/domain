11  --  Loops  (for, while, break, continue, range)

1)  What a loop is

A LOOP repeats a block of code many times. Python has two loop kinds:

     for       repeats over the items of a
               sequence (list, tuple, string,
               dict, range, ...).
     while     repeats while a condition is
               True.


2)  for  loop

Syntax:

     for <name> in <sequence>:
         <indented block>

Each round, the loop takes the NEXT item from  <sequence> , puts it into the variable  <name> , and runs the block once.

Code:

     for n in [10, 20, 30]:
         print(n)

Output:
     10
     20
     30


for  works on any iterable  --  list, tuple, string, dict, set, range.

Code:

     for c in "hi":
         print(c)

Output:
     h
     i

Code:

     for k in {"name": "adarsh", "age": 25}:
         print(k)

Output:
     name
     age


3)  range()  --  generate numeric sequences

     range(stop)              ->  0, 1, ..., stop-1
     range(start, stop)       ->  start, ..., stop-1
     range(start, stop, step) ->  stepwise

The  stop  is NOT included.

Code:

     for i in range(5):
         print(i)

Output:
     0
     1
     2
     3
     4

Code:

     for i in range(2, 6):
         print(i)

Output:
     2
     3
     4
     5

Code:

     for i in range(0, 10, 2):
         print(i)

Output:
     0
     2
     4
     6
     8

Descending:

Code:

     for i in range(5, 0, -1):
         print(i)

Output:
     5
     4
     3
     2
     1


4)  Loop with an index using enumerate()

Sometimes you want BOTH the index and the item. Use  enumerate() .

Code:

     names = ["adarsh", "priya", "rahul"]
     for i, name in enumerate(names):
         print(i, name)

Output:
     0 adarsh
     1 priya
     2 rahul


5)  while  loop

Syntax:

     while <condition>:
         <indented block>

The block runs OVER AND OVER as long as the condition is True. Every round, the condition is checked FIRST. If it is False right away, the block never runs.

Code:

     count = 0
     while count < 3:
         print(count)
         count = count + 1

Output:
     0
     1
     2

Critical: something inside the loop must CHANGE so that the condition eventually becomes False. Otherwise you have an infinite loop.


6)  break  --  exit the loop early

break  ends the loop immediately, no matter what the condition says.

Code:

     for n in [1, 2, 3, 4, 5]:
         if n == 3:
             break
         print(n)

Output:
     1
     2

The loop stopped as soon as  n == 3  was true. Values  4  and  5  are never seen.


break  works in both  for  and  while :

Code:

     while True:
         answer = input("type quit: ")
         if answer == "quit":
             break
     print("done")

The  while True  loop looks like it runs forever, but the  break  gives it an exit door.


7)  continue  --  skip to the next round

continue  ends the CURRENT round and jumps straight to the next one.

Code:

     for n in [1, 2, 3, 4, 5]:
         if n % 2 == 0:
             continue
         print(n)

Output:
     1
     3
     5

For each even  n , the  print  line is SKIPPED and Python moves on to the next value.


8)  Nested loops

A loop can sit inside another loop. The inner loop runs completely for EACH pass of the outer loop.

Code:

     for x in [1, 2, 3]:
         for y in ["a", "b"]:
             print(x, y)

Output:
     1 a
     1 b
     2 a
     2 b
     3 a
     3 b


break  and  continue  affect only the LOOP THEY ARE IN (the innermost one).


9)  else  clause on loops  (brief)

Both  for  and  while  can have an  else  block. It runs when the loop finishes normally (no  break ).

Code:

     for n in [1, 2, 3]:
         print(n)
     else:
         print("done")

Output:
     1
     2
     3
     done


If a  break  ends the loop early, the  else  block is SKIPPED.

Code:

     for n in [1, 2, 3]:
         if n == 2:
             break
         print(n)
     else:
         print("done")

Output:
     1

The  "done"  is not printed because the  break  fired.


10)  Common errors

  (a)   Infinite  while  loop

        Code:

           count = 0
           while count < 3:
               print(count)

        The loop runs forever because  count  is never updated. Add  count = count + 1  inside the block. If you get stuck in an infinite loop, press  Ctrl + C  in the terminal to stop the program.


  (b)   Off-by-one with  range

        Code:

           for i in range(1, 5):
               print(i)

        Output:
           1
           2
           3
           4

        The  5  is NOT printed because  range(start, stop)  stops BEFORE  stop . To include 5, use  range(1, 6) .


  (c)   Modifying a list while looping over it

        Code:

           nums = [1, 2, 3, 4]
           for n in nums:
               if n % 2 == 0:
                   nums.remove(n)
           print(nums)

        Output:  [1, 3]

        The output looks right for this small case, but on larger lists this pattern silently SKIPS items.

        Do not add or remove items from a list you are looping over. Loop over a COPY  ( for n in nums[:] ) , or build a NEW list.


  (d)   Wrong indentation

        Same as with  if  : the block under  for  or  while  must be indented. A missing indent gives an  IndentationError .
