    domain/

    |    |    +-- ...
    |    +-- phase_b/                 (created when Phase B begins)
    |    +-- ...
    +-- programs/                     <- hands-on code
         +-- index.htm
         +-- script.js
         +-- style.css
         +-- hello.py
         +-- ...


notes/   --  learning material  (plain .txt only)

  -  instructions.txt
       The contract you are reading right now. It
       lives directly inside  notes/  .

  -  One folder per phase, inside  notes/ :
       phase_0/ , phase_a/ , phase_b/ , ... ,
       phase_m/
       (lowercase, snake_case).

  -  Inside each phase folder:
       intro.txt
          The short list of small parts that phase
          is made of.
       N_topic_name.txt
          One file per section of that phase, where
          N is the section number and topic_name
          is a short, lowercase, snake_case
          description.

  -  When we START a new section (for example A.2),
     create a new file  2_first_program.txt  inside
     the correct phase folder and add the content
     there.

  -  When we START a new phase (for example Phase B),
     create a new folder  notes/phase_b/  , put an
     intro.txt  inside it listing that phase's
     parts, and add section files as we teach them.

  -  All learning content stays in plain  .txt
     files. No markdown, no code files here.


programs/   --  hands-on practice  (actual code files)

  -  Holds real code files that Adarsh types out
     and runs while learning. This is where the
     examples from the notes are actually tried.

  -  FLAT structure. No phase subfolders. Every
     file sits directly inside  programs/  .

  -  File names use whatever extension matches
     the language:  .py  for Python,  .htm  /
     .html  for HTML,  .css  for CSS,  .js  for
     JavaScript, and so on.

  -  If a topic needs multiple files (for example
     an HTML page with its own CSS and JS), keep
     them side by side at the top of  programs/ .

  -  The notes files stay pure teaching text; the
     runnable code stays here.
